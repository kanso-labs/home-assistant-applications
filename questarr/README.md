# Home Assistant Application: Questarr

Game library manager inspired by the arr applications.

Questarr finds the games you want through IGDB, tracks them, and sends releases
to your downloaders through your indexers or Prowlarr, then imports what
arrives.

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]
