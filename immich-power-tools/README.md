# Home Assistant Application: Immich Power Tools

Bulk tools for organizing an Immich library.

It does in bulk what Immich's own interface does one photo at a time: it merges
the people Immich split, fills in missing locations, finds albums waiting to be
made, and shows analytics across your photos. It runs beside the Immich
application.
