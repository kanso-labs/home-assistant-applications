# Home Assistant Application: Seadexerr

Prowlarr indexer that offers the SeaDex release of each anime, so Sonarr and
Radarr can prefer the best one.

Seadexerr has no licence, so this repository publishes no image of it: your Home
Assistant builds the application itself, from the image Seadexerr's author
publishes.
