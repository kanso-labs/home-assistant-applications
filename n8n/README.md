# Home Assistant Application: n8n

Workflow automation that connects your services and Home Assistant, with a
visual editor, code steps and AI nodes.

n8n opens inside Home Assistant through ingress, and Home Assistant can call its
webhooks with no port published. Credentials for Home Assistant, and for the
Mosquitto broker and MariaDB once they are installed, are made for you.
