# Home Assistant Application: Immich Machine Learning

Face recognition and smart search for the Immich application.

It runs Immich's machine learning on an Intel GPU through OpenVINO, and on the
processor where there is none. Install it alongside the Immich application,
which sends it the work.

![Supports amd64 Architecture][amd64-shield]
