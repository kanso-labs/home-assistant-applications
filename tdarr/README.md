# Home Assistant Application: Tdarr

Automates work on your media library through flows of FFmpeg, HandBrake and
MKVToolNix steps.

Tdarr remuxes, cleans up tracks, extracts subtitles, transcodes and checks files
for corruption, one file at a time, as they arrive. It is built on your Home
Assistant rather than downloaded, because Tdarr's licence does not allow it to
be redistributed.
