# Home Assistant Application: NAT Gateway

Shares this host's network connection with a device plugged straight into a
spare Ethernet port, such as a NAS.

The device reaches the internet through Home Assistant, for its updates, its
clock and its cloud services, while nothing else on the network can reach it. It
has no web interface: the one option names the port.
