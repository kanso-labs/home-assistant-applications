# Home Assistant Application: Traefik

Reverse proxy that sends each request to the application its host name belongs
to.

Give each application a name of its own, such as `sonarr.home.local`, and reach
them all through one address. Simple routes are set in the Configuration tab,
anything more in Traefik's own configuration files, and its dashboard opens from
the Home Assistant sidebar.
