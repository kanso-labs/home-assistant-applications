# Home Assistant Application: Muxarr

Strips unwanted audio and subtitle tracks from your media.

Muxarr remuxes rather than re-encodes, so a file is rewritten in about a minute
with no loss of quality, and Sonarr and Radarr can hand it new imports as they
arrive.
