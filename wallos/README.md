# Home Assistant Application: Wallos

Tracks your subscriptions, what each costs a month and when it renews, totalled
in one currency.

Wallos sends a notification before each payment, by email, push, or a webhook
into Home Assistant, and converts every price into your main currency with daily
exchange rates.
