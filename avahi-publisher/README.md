# Home Assistant Application: Avahi Publisher

Publishes extra `.local` names and Bonjour services on your network with Avahi.

Give an application a name of its own, such as `sonarr.local`, or announce a
service for a device that does not announce its own. It runs the official Avahi
and has no web interface: everything is set from the application's options.
