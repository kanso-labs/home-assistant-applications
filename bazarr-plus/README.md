# Home Assistant Application: Bazarr+

Subtitle manager with a provider marketplace and AI translation.

Bazarr+ is a fork of Bazarr that adds a plugin catalogue of subtitle providers,
bilingual subtitles, and translation through OpenRouter or embedded tracks.
